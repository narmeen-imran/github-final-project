Paradise Nursery Shopping Application

A dynamic, interactive React-based e-commerce web application built for **Paradise Nursery**, an online plant shop. This project was developed as part of the React Final Project curriculum to demonstrate skills in component-driven UI development, dynamic state management using Redux Toolkit, and modern CSS layout design.

---

## 🚀 Features

- **Landing Page**: Visually appealing homepage introducing Paradise Nursery, featuring a background hero image, company overview, and an interactive "Get Started" call-to-action button.
- **Product Catalog**:
  - Organised into **3 categories**: Air Purifying, Aromatic, and Medicinal Plants.
  - Displays **6 unique houseplants per category** (18 items total), complete with thumbnails, descriptions, and pricing.
  - Interactive **"Add to Cart" buttons** that update state dynamically and disable automatically once an item is added to prevent duplicate additions.
- **Dynamic Navigation & Header**:
  - Global navigation bar linking across Landing, Product Listing, and Cart views.
  - Interactive cart icon displaying real-time total item counts.
- **Shopping Cart Management**:
  - Detailed itemized list with thumbnail images, names, and unit prices.
  - Dynamic **subtotal calculation** per item and total shopping cart amount.
  - **Quantity adjustment controls** (`+` and `-`) that calculate total prices live.
  - Item removal/deletion functionality.
  - **"Continue Shopping"** button to seamlessly return to the product listing page.
  - **"Checkout"** button configured with an interactive alert message (*"Coming Soon"*).

---

## 🛠️ Tech Stack & Dependencies

- **Frontend**: React (Vite / Create React App)
- **State Management**: Redux Toolkit (`@reduxjs/toolkit`), `react-redux`
- **Styling**: CSS3 (Flexbox/Grid, Custom CSS variables, background overlay design)
